# Mini Ledger System (Laravel)

A simple **mini accounting ledger system** built with Laravel. This system allows users to register/login, record transactions (debit/credit), view account balances, and see recent transactions in a clean UI.

---

## Features

- User authentication (Register & Login required)
- View account balances
- Record new transactions (Debit / Credit)
- Transaction notes
- Recent transactions table
- JSON API for ledger reports
